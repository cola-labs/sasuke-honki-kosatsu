SECTION 05 / WHAT HAPPENED

「外れた」を
一言で終わらせない

本番後に失敗・成功の仕方まで調査し、Observed Fact → Mechanism → Ability / Demand解釈を分離した。 一回の失敗を、そのまま「能力不足」とは扱っていない。

SECTION 07 / LEARNING

今回の大会から
何を持ち帰る？

一大会だけでFrameworkの優劣は決めない。 ただし、次回以降に検討する価値が高いTargeted Review Candidateは見つかった。

Stage-transition operator

4人aggregate → 1代表 → 4人points sum → 1代表。ステージごとに評価単位が変わる。

PRIORITY HIGH

15m-specific representative fit

1STの速さと15m vertical climb speedは同じではない。代表1名制ではspecific fitが強く効く。

PRIORITY HIGH

3RD contribution shape

4人の均等なdepthだけでなく、森本＋山本良幸のようなtop-end anchorsが得点構造を支配する。

PRIORITY HIGH

Japan-course rule familiarity

Germanyのように、身体能力ではなくroute / rule / dynamic precisionで早期敗退するケースを分離する。

PRIORITY HIGH

UNKNOWN decision handling

UNKNOWNは低能力の証拠ではない。PolandやUSAでは、UNKNOWNの扱いがselection判断へ影響した可能性がある。

PRIORITY HIGH

FINAL preparation / execution

Specific preparation、当日のexecution、休息順などを、恒常的Abilityと同じ箱に入れない。

PRIORITY MEDIUM
Framework disposition

TARGETED_REVIEW_CANDIDATES_IDENTIFIED。 1ST・2NDのhit countはOLD/NEW同率、Finalistsはこの一大会でOLDが近く、ExplainabilityとUNKNOWN auditabilityはNEWが強かった。 一大会から「OLDが上」「NEWが失敗」と一般化はしない。

SECTION 08 / TRANSPARENCY

検証の前提

結果を知った後にForecastを書き換えない。 事前FreezeとActual Snapshotを固定し、Mechanismは「なぜ」を説明するためだけに使った。

  • OLDとNEWはActual exposure前にFreeze済み。
  • Forecastは確率モデルではない。
  • exact full rankingは予測していない。
  • Actual Result Snapshotは本番後に別途Freeze済み。
  • Mechanism EvidenceでPASS Aのhit / missを変更していない。
  • 一大会のみでFrameworkの一般的優位性を主張しない。
  • Frozen Ability / Event Demand / Adapterは事後修正していない。
  • LOW / INDETERMINATE / HOLDは無理に確定情報へ格上げしない。
