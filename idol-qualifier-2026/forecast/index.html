03 / EVENT DEMAND

競技形式と要求能力

公式発表で確認できた形式と、そこから考える勝負のポイントを分けて示します。

EVENT / 01

テイルインポッシブル

公式発表の形式

抽選で6人ずつの2組に分かれ、各組で下位2人ずつが脱落。最後に残る各組2人、計4人の最終走タイムを比較する。次走はトップのゴール後1分が基準。

独自分析 / 速さ × 反復持久力

一度速く走るだけでなく、短い休息でペースを再現できるか。早くゴールすることは、次走までの休息確保にもつながる。

未確定・留保 組分け、途中脱落者の順位処理、距離の最終確認は留保。各自が60秒休める形式ではない。

EVENT / 02

スポンジブリッジ

公式発表の形式

不安定なスポンジ板を連続して渡る競技。前半15枚＋後半15枚は発表時点の暫定案で、枚数は調整中。

独自分析 / バランス × 身体の連動

重心と体幹の軸を保ちながら足を運び、崩れかけた姿勢を修正できるか。速さの重要度は順位方式によって変わる。

未確定・留保 タイム制か到達枚数制か、挑戦回数、失敗時の処理は未確定。テイル後の疲労も、休息条件次第。

EVENT / 03

パワーフォース

公式発表の形式

つながれた相手の牽引力に抗い、自分の進行方向へ前進する対人競技。前年に導入された種目を継続する。

独自分析 / パワー × 全身の連動

脚・体幹・上半身の力を前進へ変えられるか。スタートで距離を稼ぐ局面と、低い姿勢で粘る局面を分けて見る。

未確定・留保 対戦組み合わせ、ラウンド構成、勝敗細則は未発表。握力だけで比較できる競技ではない。

EVENT / 04

SASUKEタイムレース

公式発表の形式

複数の障害を攻略する速さを競う。発表されたのは平均台、Mt.ミドリヤマ、スパイダー、そり立つ壁の4エリア。前年のハードルは削除。

独自分析 / 障害適応 × 動作のつなぎ

障害を越えられることに加え、着地・把持の後に止まらず次へ移れるか。平均台やスパイダーの安定性、壁の一発攻略も分岐になる。

未確定・留保 正式な配置・攻略順、制限時間、リタイア処理、壁の挑戦回数などは未確定。4エリアの列記は攻略順を示さない。

04 / EVENT FORECAST

競技別の根拠と分岐

同じ予想を、競技に近い実績・運動経験・残る不確実性から読み解きます。

01 / TAIL IMPOSSIBLE

テイルインポッシブル

本命大信田美月
走速度と持久力の両立、前年からの走対策を重視。短い休息で繰り返す形式への適性を見る。
対抗風見和香
300mサバイバル走など、反復走の直接実績が強み。集団の位置取りと各走の速度が分岐になる。
上位候補秋山由奈・川岸瑠那
秋山はバスケ、川岸は長年のテコンドーなどの競技体力が材料。ただし現在の反復走タイムは未確認。
穴候補須永心海
400mを4本、1分休憩で繰り返す練習は競技に近い。実際の相対ペースが見どころ。
注目清司麗菜
速さは強み。初走で確保する休息が、後半のペース維持をどこまで支えるか。
勝負の分岐

一度速く走るだけでなく、短い休息でペースを再現できるか。早くゴールすることは、次走までの休息確保にもつながる。

02 / SPONGE BRIDGE

スポンジブリッジ

本命清司麗菜
継続するスケートボードとKUNOICHI実走を評価。動きながら姿勢を保ち、修正する力が競技に合う。
対抗大村杏
平均台上の側転という、狭い支持面での直接実技が材料。安定性を重視する形式なら強みが生きる。
上位候補川岸瑠那・秋山由奈・鈴野みお
川岸は武道と体操系、秋山はパルクールやバスケ、鈴野はバレエ・新体操。異なる背景から姿勢制御に期待する。
穴候補安杜羽加・葉山雫
安杜はポールダンスなどの身体操作、葉山は長期ダンスと球技での足運びが材料。柔らかい足場への適応を見たい。
勝負の分岐

重心と体幹の軸を保ちながら足を運び、崩れかけた姿勢を修正できるか。速さの重要度は順位方式によって変わる。

03 / POWER FORCE

パワーフォース

本命大信田美月
前年の同競技準優勝を最も直接的な材料として評価。初動の速さと体幹の連動にも期待する。
対抗秋山由奈
跳び箱10段、パルクール、バスケ経験から下半身の出力と全身の連動を評価。同競技での直接実績はこれから。
上位候補川岸瑠那・大村杏
川岸は踏み込みと重心移動、大村は跳躍・全身支持の材料が強み。力を実際の前進へ変える技術を見たい。
穴候補南伊織・安杜羽加
南は腕相撲企画や球技のパワー、安杜はポールダンスの体幹操作。異なる強みが対戦相性で生きる可能性がある。
注目清司麗菜
前年は同競技で1勝。身体操作と経験が、相手に応じた勝ち筋につながるか。
勝負の分岐

脚・体幹・上半身の力を前進へ変えられるか。スタートで距離を稼ぐ局面と、低い姿勢で粘る局面を分けて見る。

06 / OVERALL

配点で変わる総合争い

2026年の公式配点は未発表。以下は前年の配点を参考にした仮定に基づく総合予想です。

REFERENCE SCENARIO / 公式配点ではありません

テイルは最大60点、パワーフォースは最大45点、タイムレースは最大80点という2025年の配点を参考にしています。新競技スポンジブリッジは、前年のビーチフラッグスと同程度の最大45点を仮置きしました。

実際の配点・順位方式・対戦組み合わせが異なれば、総合の見立ても変わり得ます。

本命

大信田美月

テイルとパワーフォースの本命、タイムレースの対抗。複数の競技に高得点を狙える柱がある。

対抗

清司麗菜

スポンジとタイムレースの本命。1位の価値が大きい配点なら、得意競技で差をつける勝ち筋が太くなる。

上位候補

秋山由奈・川岸瑠那

ともに4競技すべてで上位候補以上。広く順位点が入る方式なら、競技をまたいだ安定感が生きる。

ダークホース

大村杏

スポンジの対抗に加え、パワーとタイムレースで上位候補。走競技での上振れが総合争いへの分岐になる。

配点感度 / どこで争いが変わるか

  • タイムレースの比重が高い：清司の得意競技が総合へ強く反映される。
  • 広く順位点が入る：秋山・川岸の4競技を通した安定感が生きる。
  • 複数競技の上位入賞が重い：大信田のテイル・パワー・タイムレースが柱になる。

分析の方法

公式の競技形式と、選手の実走実績・公開された運動経験を照合し、競技ごとに予想カテゴリを整理しています。運動経験があることと、今回の競技で成功することは同一ではありません。情報の不足を能力の低さへ置き換えず、初見の障害や組分けによる不確実性を残しています。

競技別予想と、仮の配点を置いた総合予想は分けて扱います。大会前の見立てを記録し、結果判明後の検証は別に行います。
